# AfDB Core Frontend — Enterprise Dashboard

> Enterprise dashboard frontend for the African Development Bank data platform. Renders data-driven interfaces, reporting modules, and CRUD operations powered by the Core backend.

## Technology Stack
- **Framework:** Next.js 15 + React 19
- **Language:** TypeScript
- **UI Library:** Ant Design 5 + Tailwind CSS
- **State:** TanStack React Query
- **Charts:** Recharts / Ant Design Charts
- **Forms:** React Hook Form + Yup

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001)

## Repository Purpose
This is the **Core tier frontend** — the data-rich enterprise dashboard:
- Data-driven reporting interfaces
- CRUD operations for enterprise entities
- Dashboard widgets and data visualization
- Consumes RESTful APIs from `afdb_core_backend`
- Permission-gated UI components (RBAC)
